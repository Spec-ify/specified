# Spec-ified v2
This is an in progress migration from PHP to a Svelte project.

# Development
## Architecture
The Svelte app uses [Turborepo](https://turborepo.dev) to facilitate code re-use and splitting. 

`apps/web/`  contains the heart of the v2 web viewer. The entry
point for the app, `+page.svelte` is located at
`src/routes/viewer/[slug]/+page.svelte`.

*eventually*, `packages/ui` will contain re-usable Svelte components
that comprise the majority of the UI, with the long term goal of
creating a separate offline viewer.

All reports generated by spec-ify are stored in a `reports/` folder. Any reports that do not have the
`test` prefix in the name should be deleted after 24 hours.

## Prerequisites
You'll need:
- The latest stable version of node.js (and npm)

## Running
### Installing dependencies
In another terminal window:

1. Run `npm install` from the root of the repository
2. Navigate to `apps/web/`, and run `npm install`

### Running dev server
1. From the root of the repository, run `npm run dev`
2. Navigate to `/viewer/test1` served from the URL provided by the previous command in your web browser, i.e `http://localhost:5713/viewer/test1`
